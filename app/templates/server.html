How speakers find this server

A new speaker looks for its server by itself: first an address entered on its Wi-Fi setup page (under Advanced), then this server's announcement on the network ({% if server.mdns %}_harkenn._tcp and harkenn.local, on{% else %}off: HARKENN_MDNS{% endif %}), then the name harkenn. If speakers are on another network than this server, add a DNS record harkenn for it in your router.
